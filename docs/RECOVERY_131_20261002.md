## Failure and changes

The converted campaign had spawn points, but the director counted entities placed outside entity-ticking chunks or on another floor. Those entities consumed the budget without reaching the player. On a globally peaceful world, ticking vanilla monsters also disappeared and their attacks scaled to zero. The existing checkpoint regions were landmark-sized boxes, and the converted structures contained no usable checkpoint doors.

- APP `create` / `createConfigured` creates `WAITING` membership only. Players retain their position and inventory until the host explicitly starts. The start validates every member before preparation. `snapshot` exposes `mapReady`; existing framework/terminal action contracts are retained.
- Campaign countdown enters `START_ROOM`; leaving the actual starting room activates the director. Both checkpoints require all living survivors inside, nobody downed, and the native entrance doors closed. The rooms and existing openings were audited against the converted blocks. Doors restore on normal finish, and configured residual iron-door cells recover on reentry.
- Spawn selection requires an entity-ticking chunk, a nearby living survivor on the same floor, valid support and collision clearance, and a position outside safe-room interiors. Inactive entities and abandoned common infected free their budget; each chapter resets the director. Operator inspection exposes spawn rejection counts and ticking entities.
- Peaceful compatibility applies only to tagged Outbreak infected in `muxi_outbreak:campaign`; other dimensions and normal world difficulty retain vanilla behavior.
- Finale retains the existing 60-second rescue hold, three waves, and tank. Completion requires the actual finale tank's uncanceled death event; unloading or discarding a tank causes a retry instead of counting as victory.
- Departing members are removed from preparation/temporary-state tracking after restoration, preventing later room ticks from modifying their recovered inventory.

Existing MP5/Glock loadout, ammunition, 133 shared map supply entries, slot caps, healing and throwable rules were retained. This is a native checkpoint adaptation of the converted map; it does not claim complete Source MDL or puzzle-script parity. Map regeneration preserves the audited adaptation and rejects changed chapter anchors.

## Reproduce

Build with the available Minecraft 1.21.1/NeoForge 21.1.250 server libraries, Java 21 and matching framework jar:

```text
py -3.12 build.py --server <server-libraries-home> --framework <framework-jar> --java-home <jdk21> --test
py -3.12 tools/qa_recovery_engine.py --server <server-home> --framework <framework-jar> --jdk <jdk21> --home <repo>/build/<new-engine-home>
py -3.12 tools/qa_recovery_client.py --server <server-home> --framework <framework-jar> --jdk <jdk21> --game <existing-client-home> --home <repo>/build/<new-client-home>
```

Each QA home must be new and inside this repository. The engine runner refuses an occupied loopback port. Stop only the process owned by the selected QA home; do not count a forced termination as acceptance.
