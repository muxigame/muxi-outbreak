# Outbreak 地图内玩法修复与 131 实机验收

原有目录当前 dev，基线 ce3b692e9fa29f4eef50d3e7f11986971ae344ab。已认可的地图保持锁定。本轮只修改 Outbreak 物品与补给行为，公共 APP、大厅、CEF、认证和会员接口由终端 owner 维护。

## 修复结果

- 入局捕获原物品后清空临时装备，出生空手。移除自动 MP5/Glock。出生场景加入低阶 MP5 或 M870、Glock17、棒球棍三个有限武器点，实际坐标 [-8,83,6]、[-8,83,7]、[-8,83,8]。每点数量为本轮人数，每成员每点只能取一次；清空槽位或交换不再领同一点。初始枪械弹药沿用既有上限；保留原物品保存与返还。
- 原 Source 出生房有近战、医疗、胆汁和燃烧瓶，没有固定低阶枪械点。新增枪械是用户明确要求的原生适配，不能称为 BSP 原有点。133 个原点的类型、数量、位置、Pitch/Yaw/Roll 均未改。Source electric_guitar 继续使用既有 LR 棒球棍适配；物品使用现有 MC ground 渲染，不声称复制 Source 网格与姿态。
- 地面枪械标签与拾取提示改为 TACZ common gun index 的真实名称键。专服没有 ClientGunIndex，原展示链因此得到原始/泛化名称。13 种实际枪械均核对中英文键；棒球棍与燃烧瓶补正确双语标签。保留所有 IMeleeWeapon 的原 SECONDARY 分类。
- 实际不能扔的物品是 muxi_outbreak:bile_bomb，对应 weapon_vomitjar_spawn。原仅 RUNNING 允许，现 START_ROOM/RUNNING 都允许胆汁和管状炸弹，与已能使用的 LR 燃烧瓶一致。管状炸弹 120 tick 引信、胆汁落点 400 tick、诱导范围和原平衡均不改。
- Source 补给分为 105 固定点、28 导演选择点。固定点保留原规则；导演点只在队伍实际接近同层（高度差≤6、距离<24）且实体区块就绪时选择一次，避免楼上出生提前决定楼下物品。不会把固定缓存全部随机化。
- 满永久血不消耗医疗包；受伤需持续使用 100 tick，恢复缺失永久血的 80%。实机 10→18，包由1→0。临时血、队友治疗与携带限制不变。
