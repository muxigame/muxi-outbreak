# Outbreak 0.3.0 枪械、补给与原版差异审计

## 基准和来源

实际工程基准是相邻 `muxi-game-core` 的 `ChallengeInventory`、`ChallengeGuns`，不是凭记忆重新选枪。
地图基准是用户提供的 VPK 内三个 BSP 的 weapon_* 实体及两份 Director 脚本。
公共机制参考 Valve Developer Community 的 Weapon_ammo_spawn、Ammunition、Weapon_item_spawn 和 L4D2_Level_Design/Weapon_and_Item_Spawning。

## 实际配装

主武器 `tacz:hk_mp5a5`，副武器 `tacz:glock_17`，弹药 `tacz:9mm`。
读取真实枪包的弹匣容量与枪机模式，不硬编码虚构的 TaCZ NBT。
当前 MP5/Glock 的弹匣分别30/17发，备用弹药按僵尸枪战同样算法：共享口径的弹匣容量合计×4，普通弹药限制120～600，故9mm备用188发。
火箭备用算法为弹匣容量×4、限制4～12。所有枪弹属性以已加载的枪包实际数据为准。
不再发弓、箭、铁剑、盾、金苹果或牛排。本模式不复制僵尸枪战的两把主枪机制，也不把吃饱自动回血带进来。

## 五个装备位

| 快捷栏 | 规则 |
| --- | --- |
| 1 | 一把主武器 |
| 2 | 一把手枪或一把近战武器 |
| 3 | 所有投掷物合计一个，不是每种各一个 |
| 4 | 急救包、除颤器、弹药升级包等大型医疗/支援物品合计一个 |
| 5 | 止痛药、肾上腺素合计一个 |

原作允许一份大型医疗物品与一份小药同时携带，不是所有药品合起来只能一个。
服务端每 tick 同时检查背包、副手、护甲格与鼠标游标，额外限制物品转换成队伍共享拾取物，不允许藏在副手绕过限制。
普通实体自动拾取被阻止；补给需要空手右键可交互实体，持TaCZ枪时使用枪械模组的交互键（当前默认O；瞄准键不是拾取键），或使用 `/muxioutbreak supply <节点ID>`，后者同样验证距离和视线。
同类槽位满则拒绝且不减少世界库存；蹲下右键交换，原物品留在世界给队友。禁止将临时物资扔出本局。

## 世界库存和补弹

原来的六个“每位玩家靠近各送一份”的奖励点已删除，改为133个来自真实BSP的补给节点。
每个节点保留 Source classname、hammer ID、origin、count 和 spawnflags；具体值可从战役JSON追溯。
库存属于整队世界，不属于玩家。有限补给取走便减少，不因离开范围、进入安全屋、受伤或 Director 节奏变化重新生长。
14处固定弹药堆可重复补足当前可补武器的匹配备用弹药；不直接装填弹匣，不发医疗/投掷物，不超过携弹上限。
普通弹药堆不补RPG，也不补由本模式用于映射L4D M60的M249。无限武器源遵守原实体的无限标志。

## 医疗与爆炸物

急救包持续使用5秒，治疗缺失永久生命的80%；受到伤害打断且不吞掉药包。
止痛药增加最大生命50%的临时血，肾上腺素增加25%并给予15秒加速；临时血逐渐衰减且不把永久血带到1以下。
常规救援5秒，救援者有肾上腺素则3秒。除颤器在倒地后被淘汰队友的记录位置附近持续使用3秒，恢复50%生命。
安全屋保留幸存者伤势、背包和倒地次数，不自动满血、不免费补药；真正淘汰者在换章恢复。
高爆弹药包占大型支援位，部署为4份共享升级站，每人一次、一个主武器弹匣。升级计数跟随枪本身，不能换枪转移或复制。

已接入 LR Tactical 1.21.1 的原生M67、燃烧瓶等扩展资源。原地图的燃烧瓶使用LR原生物品；土制炸弹和胆汁瓶用本模组原生机制保留诱敌差异，不把它们冒充为普通破片手雷。
战役地图保护只排除爆炸的方块破坏，保留爆炸对实体的伤害/冲击；不能再取消整个 ExplosionEvent.Start。
燃烧区域、弹体、爆炸延迟物等属于本局，换章/退局清理，避免留给下一局。
M67等新包物品可用于服务器其他玩法，但不会无依据插入原地图原本没有的随机池。

## Director：已改进但不是逐项原样复制

补给选择与刷怪节奏分开。固定物品不随机改成其他类型；随机节点只在BSP允许的候选池内选择；must-exist约束被保留。
每个本局未见节点只决定一次，团队血量与已有医疗量影响自建选择权重，有限库存耗尽后不会重抽。
刷怪Director加入章节内NAV路线推进度，不再仅用章节序号。强度仍参考血量、伤害、分离、感染者和倒地压力。

不能称为“与Valve所有细节完全一致”：随机数、密度求解、可见性裁切与医疗替换权重不是对Valve内部实现的逐行移植。
原图 `ls_fangshou.nut` 明确配置300人尸潮、最多7特感（Boomer2/Spitter2/Smoker2/Hunter1），`sf3_start.nut` 配置200人尸潮、最多5特感（Boomer4/Charger1），均禁止导演自然生成Boss且偏好上方刷新。
本版没有把这两套Source脚本直接执行；Minecraft仍采用自身有限实体预算、原生事件与60秒三波/Tank撤离改编。不能把“Director存在”写成“原图Director完整复刻”。

跨BSP安全屋的Source实体 globalname/库存转场合并、拾取镜头动画、原物理携带槽、无限手枪弹药、原版枪械伤害、黑白视效等也未宣称一比一。
本版手枪使用现有僵尸枪战同款真实9mm有限弹药；原GL/M60分别映射现有RPG/M249，不是原枪弹道/伤害等价物。

## 输入遗漏必须可见

146个源weapon实体中导入133个：72个在源位置附近进行最多3格水平/5格垂直的地面适配；13个未导入并逐项记录于 `build/source-supply-report.json`。
其中为汽油桶/搜集道具/链锯及2个附近找不到安全拾取面的武器点，不会悄悄替换为药品。它们涉及此前未移植的Source道具模型/谜题，不算已完成。

## 第三方依赖风险与回退

新增 `LesRaisins-Tactical-Equipements-1.21.1-0.4.3.jar`，Modrinth项目zSKr1DYY、版本fcwJFQFG，文件摘要锁定在dependencies.json。
这是Nahiyus512维护的**非官方早期NeoForge移植**，不是原团队官方稳定版。其README明确警告可能损坏重要存档，原作者尚未完整测试多人/着色器/其他模组组合。
本工程会额外做真实NeoForge客户端、独立服务器和完整Better MC副本测试，但这不能保证长期存档安全。
部署不重启正式服；正式启用前应取得可恢复的完整世界备份。本轮安装脚本仅备份旧JAR，不冒充已经备份在线世界。
回退时应同时还原旧Outbreak JAR并移出LR JAR；启用过新注册物品的存档不能靠删JAR保证无损，需使用启用前存档备份。
LR源码GPL-3.0、素材保留原授权，使用发布的独立JAR，不把其素材复制进自编模组，不上传依赖二进制到本仓库。

## 测试层次

12项Python测试与Java Director/3110条补给规则断言。
0.3.0需要TaCZ/LR客户端网络通道，旧0.2.0的纯原版协议机器人已实测不能登录；禁止复用旧45项网络断言作为0.3证据。
新装备引擎测试使用真实ServerPlayer与真实世界、物品使用、子弹和爆炸tick，但通过无网络传输测试对象驱动，报告明确标为engine而非双网络客户端。
测试专用 `muxi-outbreak-QA-ONLY.jar` 只能在127.0.0.1独立实例和专门JVM开关下启动，绝不部署生产。
实际图形网络客户端与完整整合包检查分别记录；自动化传送/清敌不等于全程人工走图和实战平衡。
